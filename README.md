### 🔐 [aws-iam-user-automation](https://github.com/root-whoami/aws-iam-user-automation)
**Automated AWS IAM User Provisioning, Group Management, and Credential Security**

<p align="center">
  <img src="https://img.shields.io/badge/AWS_CLI_v2-232F3E?style=for-the-badge&logo=amazon-aws&logoColor=white" alt="AWS"/>
  <img src="https://img.shields.io/badge/Bash_Scripting-4EAA25?style=for-the-badge&logo=gnu-bash&logoColor=white" alt="Bash"/>
  <img src="https://img.shields.io/badge/OpenSSL_Crypto-7209B7?style=for-the-badge&logo=shield&logoColor=white" alt="OpenSSL"/>
  <img src="https://img.shields.io/badge/POSIX_Security-00F5D4?style=for-the-badge&logo=linux&logoColor=black" alt="Security"/>
</p>

</div>

```text
  [ Terminal Execution Flow ]
  ├── 1. check_prerequisites() ──> Validates AWS CLI, OpenSSL, and STS Caller Identity
  ├── 2. ensure_group_exists() ──> Idempotently verifies or creates 'Developers' IAM group
  ├── 3. get_usernames()       ──> Sanitizes input (alphanumeric + symbols, rejects duplicates)
  ├── 4. process_user()        ──> Skips existing IAM users; provisions new user accounts
  ├── 5. generate_password()   ──> Generates cryptographically secure passwords via OpenSSL
  ├── 6. enforce_security()    ──> Applies --password-reset-required on first AWS console login
  └── 7. secure_output_sink    ──> Writes credentials to users_passwords.txt with chmod 600
```

* **Core Highlights:** Input validation via regex whitelist (`^[a-zA-Z0-9+=,.@-]{1,64}$`), duplicate rejection, idempotent group and user checks, OpenSSL random passwords, forced first-login password reset, and restricted `chmod 600` file output.
* 🔗 **View Project Repository:** [https://github.com/root-whoami/aws-iam-user-automation](https://github.com/root-whoami/aws-iam-user-automation)
