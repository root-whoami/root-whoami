## 🛡️ DevOps Core Principles

| Principle | Engineering Application |
| :--- | :--- |
| 🔒 **Least Privilege First** | Never use wildcard (`*`) access. Craft granular, auditable IAM policies tailored strictly to operational requirements. |
| 🔁 **Idempotent Automation** | Design scripts to run safely multiple times without generating duplicate accounts, conflicting state, or orphan resources. |
| 🛡️ **Defense-in-Depth** | Enforce POSIX file lockdowns (`chmod 600`), strict `.gitignore` rules, and mandatory first-login password rotation. |
| 📜 **Declarative Workflows** | Transitioning manual shell tasks into containerized definitions and Terraform-managed infrastructure as code. |

### 🔐 [aws-iam-user-automation](https://github.com/root-whoami/aws-iam-user-automation)
**Automated AWS IAM User Provisioning, Credential Security & Group Management**

<p align="center">
  <img src="https://img.shields.io/badge/AWS_CLI_v2-232F3E?style=for-the-badge&logo=amazon-aws&logoColor=white" alt="AWS"/>
  <img src="https://img.shields.io/badge/Bash_Scripting-4EAA25?style=for-the-badge&logo=gnu-bash&logoColor=white" alt="Bash"/>
  <img src="https://img.shields.io/badge/OpenSSL_Crypto-7B2CBF?style=for-the-badge&logo=shield&logoColor=white" alt="OpenSSL"/>
  <img src="https://img.shields.io/badge/POSIX_chmod_600-00F5D4?style=for-the-badge&logo=linux&logoColor=black" alt="Security"/>
</p>

</div>

```text
  [ Terminal Execution Workflow ]
  ├── 1. check_prerequisites() ──> Validates AWS CLI, OpenSSL, and STS Caller Identity
  ├── 2. ensure_group_exists() ──> Idempotently verifies or creates 'Developers' IAM group
  ├── 3. get_usernames()       ──> Sanitizes input (alphanumeric + standard symbols, rejects duplicates)
  ├── 4. process_user()        ──> Skips existing IAM users; provisions new user accounts
  ├── 5. generate_password()   ──> Generates cryptographically secure passwords via OpenSSL
  ├── 6. enforce_security()    ──> Applies --password-reset-required on first AWS console login
  └── 7. secure_output_sink    ──> Writes credentials to users_passwords.txt with chmod 600
```

* **Core Highlights:** Robust input validation, idempotency, forced password reset, group attachment, and credential lockdown.
* 🔗 **View Project Repository:** [https://github.com/root-whoami/aws-iam-user-automation](https://github.com/root-whoami/aws-iam-user-automation)
