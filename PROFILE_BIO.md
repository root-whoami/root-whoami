# GitHub Profile Bio Options

GitHub user profile bios have a strict **160-character limit**. Below are 3 professional, accurately positioned bio options tailored for an entry-level DevOps engineer.

---

### Option 1 (Recommended)
```text
Aspiring DevOps Engineer | AWS, Linux, Python & Bash | Cloud Automation | Learning Docker, Kubernetes & Terraform
```
* **Character count:** 114 / 160
* **Rationale:** Clearly identifies your career direction, highlights your core technical stack (AWS, Linux, Python, Bash), specifies your primary discipline (Cloud Automation), and transparently states what you are actively learning without exaggeration.

---

### Option 2 (Technical & Systems Focus)
```text
Entry-Level DevOps Engineer | Linux, Python & Bash Automation | Hands-on AWS Labs | Exploring Docker, K8s & Terraform
```
* **Character count:** 116 / 160
* **Rationale:** Emphasizes practical systems administration and script-driven automation while highlighting in-progress technologies.

---

### Option 3 (Minimal & Clean)
```text
Cloud & DevOps Learner | Linux SysAdmin, Python & Bash | Building on AWS | Aspiring DevOps Engineer
```
* **Character count:** 101 / 160
* **Rationale:** Concise, straightforward, and focused on core strengths and immediate career objective.

---

## How to Set Your Bio on GitHub
1. Log in to [GitHub](https://github.com/).
2. Click your profile picture in the top-right corner and select **Your profile**.
3. Click the **Edit profile** button beneath your avatar.
4. Paste your selected bio into the **Bio** text box.
5. Click **Save**.
