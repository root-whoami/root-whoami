# GitHub Profile Banner Guide

A header banner placed at the top of your GitHub profile README or social preview creates an immediate visual identity that signals your technical specialty.

---

## 🎨 Recommended Visual Concepts

1. **Subtle Cloud & Network Nodes:**
   * Abstract connected graphs, mesh networks, or clean architectural node diagrams.
   * Palette: Deep navy (`#0d1117`), slate grey, muted cyan/blue accents matching GitHub dark mode.

2. **Terminal / CLI Theme:**
   * A clean terminal prompt aesthetic (e.g., stylized prompt showing `whoami`, `aws sts get-caller-identity`, or clean shell output).
   * Monospaced typography with syntax-highlighted accents (greens, cyans).

3. **Minimal Infrastructure Blueprint:**
   * Line-art representation of servers, containers, or cloud topology.
   * Minimalist, uncluttered layout with subtle geometric gridlines.

---

## 📐 Technical Specifications

* **Recommended Dimensions:** 1280 × 320 px (4:1 aspect ratio) or 1200 × 300 px.
* **Format:** Web-optimized SVG or high-resolution PNG (under 1 MB for fast loading).
* **Color Compatibility:** Design with dark-mode contrast in mind (as most developers and technical recruiters browse GitHub in dark theme).

---

## 🚫 What to Avoid
* Overly bright, saturated, or flashy neon color palettes.
* Copyrighted enterprise logos (avoid pasting commercial vendor marketing assets).
* Buzzword tag clouds or giant lists of 40 different tech icons.
* Fast-looping or distracting GIF animations that slow down page rendering.

---

## Recommended Free Design Tools
* **Figma:** Excellent for authoring crisp vector shapes, custom dimensions, and clean typography.
* **Canva / Excalidraw:** Quick for geometric network diagrams or handwritten architectural sketches.
